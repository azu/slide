# Codex Editing Notes

このディレクトリのスライド、発表者ノート、図の文言を編集するときは、まず `japanese-writing-guidelines.md` を参照する。

## 日本語表現

- 感覚語や比喩よりも、対象、範囲、関係、条件、経路を明示する。
- `刺さる`、`効く`、`主戦場`、`地図`、`化ける`、`ジャンプ`、`固める`、`塞ぐ` のような語を本文やノートに追加しない。
- SLSA は「達成レベル」ではなく「脅威モデル」または「分類」として説明する。
- npm publish の話では、`Artifact publication(F)`、`publish 経路`、`権限境界`、`Approve stepを置く`、`緩和策` のような具体的な語を使う。

## Slide Tone

- スライド本文は短く、発表者ノートで補足する。
- 攻撃シナリオは説明してよいが、煽りや戦闘的な比喩に寄せない。
- 対策の説明は「何に対応するか」「どの経路を制限するか」「どの段階で review を追加するか」を明示する。
